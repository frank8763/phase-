# V686 空白场地分层能力验证

用户2026-11-01明确提出改变策略，先在原场地或空白场地验证检测未知动态障碍、规划新路径及跟随通过。先做能力课程评测，依据失败环节再决定训练对象。本轮不修改冻结Phase20/Phase6，不以现有全接管几何控制结果充作SAC训练效果。

NEW独立1800秒窗口，从execute_curriculum.py启动计时，最多一次零积分场景预检、一次导航、仅严格到达且全审计通过后一次同版本完整重复。新几何数量1、独立确认0、训练更新0。旧窗口和失败不复开。本轮无算法修订/刷种子/自动续窗，任何安全/模型/源码/真值泄漏异常停批。初始化工具错误最多一次保留失败的修复重试；不改算法/任务/门槛/原绝对截止。

固定种子95000011仅加载原车；这是明确新任务OPEN_SINGLE_CROSSING_01，不能称同旧模型或配对比较。10x10空白场地，原20已知静态障碍在场景构造期移走且碰撞关闭，保留车/地面动力学和传感器。构造期初态(-3,-2,0)，目标(1,-2)，4米直行参考。单未知圆柱直径0.20m，锚点(-1,-2)，横向y正弦振幅0.25m、速度上限0.08m/s，原噪声/漏检/3m范围/47束不变。完整扫掠离原中央口保护区>0.05m，需原离线全自体绕行参考>=0.15m。没有墙体，通道不会被封死；这不等于更困难原场地已解决。

算法冻结为V680全部因果感知/当前占据空间搜索/原生时间准入/保留后备及合法命令映射；不读准确当前状态、真实未来或扫掠。开始最多32公开步实际安全观测，不能直接冻结机器人。原观测阶段仍需每步通过原2.4秒准入；运动障碍每原生步更新。预检与规划参考仅用已知空白地图，真实扫掠只做评价和任务可通行证书。

逐层记录，不合并PASS：
1. 检测：首检测时刻、有效未知回波数/占比、位置误差与原329未来点覆盖；>=5有效帧且覆盖通过称此例有检测证据。识别运动需至少一坐标速度区间排除0或两时刻位置区间互斥，仅检测圆柱不能叫辨识速度。
2. 规划：与已知空白地图原参考比较，检测后GLOBAL_GOAL_PATH、原完整自体密集净空>=0.155m、绕行横偏>=0.20m，且原直行参考在当次因果场中不安全，才记绕行规划证据。空间路线存在不等于时序执行可行。
3. 跟随通过：严格实际到达距离<=0.45m、原生净空>=0.15m、接触/穿透/未知0、完整自体域覆盖/无积分外根状态改写、全状态/原始ctrl重放误差<=1e-8。任务最多600公开/4800原生，540秒soft/600秒hard。原2.4/3.28秒安全时域、.155准入、自体.002、末速.025和执行器范围/速率均不降低。每个任务后完整原生重放、独立日志核验；私有预测原数量逐项保存，不计样本。

若未到达，分析是哪层先失败，停止本轮，不用重复“训练一次”或添加更容易几何掩盖负例。若成功，只有同一个空白开发例通过，后续再单列不同初态/相位、速度及回原场地课程。SAC若要训练必须另外定义新可训练checkpoint、输入输出、有限更新预算和冻结留出集，原Phase20不覆盖。本轮全部实际积分经run_phase.sh，单CPU顺序，输出仅runs/v686_dynamic_open_curriculum；Stage/实机0。
