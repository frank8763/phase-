# Phase汇报文字与视频说明

核对日期：2026年11月2日。可直接拆成8页PPT；下文“已实现”“已验证”和“尚缺证据”分别表述。

## 第1页｜研究目标与当前结论

**建议标题：面向未知障碍的感知—规划—执行一致导航与可验证恢复**

- 平台：具有转向、车轮执行器和机械臂自体几何的移动机器人，在MuJoCo中按真实动力学执行。
- 问题：已知基础地图、定位已知，但局部障碍起初不在规划先验中；机器人需要通过真实测距发现障碍、重新规划并到达目标。
- 静态：V657有限预注册基准23/24严格到达，单障碍12/12、双障碍11/12，达到本轮工程验收门槛；保留1项未到达。
- 动态：8米受控课程中，两种初相位的“行驶中发现—停车—重规划—继续—到达”及各自完整重复已通过；新24项独立确认因初始化问题未进入导航。

讲述口径：静态有限工程验收已通过；动态功能链已有开发证据，稳定性与泛化确认仍未完成。

## 第2页｜主要方法：六个模块组成闭环

1. **因果感知与障碍记忆。** 只使用已知地图、自车状态和当时已有的LiDAR/深度测距。过滤饱和量程与已知实体回波，保留有效未知障碍信息；转向或短时失观测不会直接删除障碍。
2. **全车身几何规划。** 使用覆盖整车与机械臂自体投影的安全域，在SE(2)位置—朝向空间进行Hybrid A*式搜索，允许前进、倒车，并检查曲率、换向和密集路径段净空。固定搜索扩展量便于复现。
3. **解析/学习控制提案。** 由参考路径生成Ackermann控制候选；近期动态课程加入通过有限示范监督学习得到的机动提案网络。提案无执行权限，必须继续经过安全准入。
4. **原生动力学安全准入。** 在只有机器人与地面的私有MuJoCo模型中预测完整关节状态、速度和实际控制，显式执行转向/轮速限幅与速率限制、制动过程，逐原生步检查完整自体和障碍净空。
5. **可保留的有限后备。** 普通首动作之后还须有一条已验证的制动/退让尾段；保存具体控制、时间和完整状态。新证书通过后才替换旧证书，无法更新时按原证书执行。
6. **执行—观测—审计反馈。** 通常只执行首个公开控制步，再用新测量更新估计和准入；同时记录原生接触、控制和完整状态，另做独立重放核验。

图示文件：`phase_method.png` / `phase_method.svg`。

必须说明：当前静态版本的几何恢复控制可覆盖全部SAC轮控；冻结SAC的独立收益尚未隔离。近期新增学习模块是**监督学习的控制提案网络**，本轮没有重新进行SAC训练。

## 第3页｜动态扩展与安全条件

- **动态占据表示：** 用有界测距噪声、首次命中/未命中必要约束和历史观测，构造位置—速度联合外覆盖；按声明的速度/加速度界预测未来占据。均值估计不能替代安全外集合。
- **规划与执行分开：** 最新开发把路线参考的因果占据投影前瞻从3.28秒扩大到6.56秒，使车辆更早绕开潜在不可续接区域；实际执行仍按原生动力学逐步核验，空间路线本身不授予执行权限。
- **途中发现后的停车：** 由真实有效回波触发；确认车辆已正常行驶，再完整执行41公开步/328原生步制动，停稳后重新规划。
- **有限后备管理：** 候选首步加完整后备都通过才可执行；末端若不能续接，应明确记录未到达，不能把安全停车算成功。

可放在图旁的参数：

| 项目 | 当前实现/验收口径 |
|---|---|
| 原生积分间隔 | 0.01秒 |
| 公开控制间隔 | 0.08秒，即8个原生步 |
| 普通控制预测 | 2.4秒，包含制动后缀 |
| 首步与后备合计 | 3.28秒 |
| 最新路线投影前瞻 | 6.56秒，仅路线提案 |
| 候选净空准入 | 至少0.155米 |
| 实际原生步净空门槛 | 至少0.15米 |
| 制动末速门槛 | 不超过0.025米/秒 |
| 严格到达门槛 | 距目标不超过0.45米，且安全/审计条件满足 |

边界：有限时域、原生采样时刻的仿真审核，不等于连续时间、模型失配下的无限安全或递归可行性证明。

V695的障碍从t0真实存在于起点锚点前方3.4米，原3米传感自然进入视野；第32/33步在正常运动后发现，完整制动后新规划并到达。没有瞬移生成、隐藏回波或积分外停车。

注意：该受控任务有“起步时3米内无未知障碍中心”的公共先验；它不覆盖任意遮挡下近距离突然闯入。两相位重复属于可复现性证据，不是新增独立样本。

## 第6页｜当前长距离问题：算法与工程分别说明

**问题一：几何上有路，不代表在当前信息与执行器约束下能安全接续。**

- 旧V691在第408步停止，仍距目标4.608米。当前因果占据下空间探针能找到路线，但将未来占据投影为静态障碍后，起点检查直接拒绝。
- 第408步锁定状态的99个预注册动作都未满足完整净空/停车证书；这只是否定该有限动作库，不能证明所有控制无解。
- 说明困难在于未来不确定性、路线时序和有限后备可续接的耦合；不能简单归因于“看不到”“物理封路”或“跟踪必然很差”。
- 6.56秒前瞻使更早绕行，在两种8米开发任务中改善了完整通行；尚无独立新池证明其普遍有效。

**问题二：新长距离课程仍耦合旧场景初始化，阻止了独立确认。**

- V696的第12项还没构建实际8米场地，就先执行旧随机长距离场景检查。
- 临时场景连续采样距离7.691979米，栅格对齐后7.722580米，超过旧上限7.7米，触发初始化拒绝。
- 因而24项导航全部未执行。这是初始化管线的问题，不能说成8米动态导航发生碰撞，也不能说成0/24导航成功。

**问题三：更长距离与论文所需证据尚未建立。**

- 目前没有大于8米的已通过记录；原复杂墙体场地动态稳定性仍未解决。
- 当前依赖准确自车定位、圆柱尺寸/形状先验、有界测距噪声及运动界，尚无充分模型失配与遮挡突入验证。
- 计算仍偏重：V657本机确认分支墙钟约为仿真时长中位数6.29倍；没有建立在线实时性或实机结果。
- 有限停车尾不自动保证可继续通行；强基线、等预算对照、机制消融与独立新任务是后续论文证据重点。

## 第7页｜下一步工作顺序

1. 将实际8米课程的场景构造从旧随机场景初始化解耦；分别管理场景、传感噪声和障碍运动参数，先做全池零积分构造测试。
2. 保留原失败账目，再冻结新算法与新确认清单，验证至少23/24严格到达、两组各至少11/12及完整重复；不替换失败种子。
3. 确认完成后再进入10米/12米等距离课程，单独评价路径长度、停滞、恢复次数、计算耗时及失败类型。
4. 做同信息、同车身域、同执行器约束、同计算预算的基线与消融，分别检验不确定性表示、路线前瞻、学习提案和后备接续的收益。

这些是后续计划，当前素材制作没有启动新实验、训练或实机。

## 第8页｜汇报结论与主张边界

可直接使用的结论句：

> 我们已建立因果感知、全车身路径规划、原生动力学准入和有限后备接续组成的闭环。静态未知障碍的有限基准达到23/24工程门槛；动态8米途中发现的两相位开发与完整重复已通过。当前主要瓶颈是未来不确定性下的持续可续接，以及独立确认管线的初始化解耦，动态稳定性与更长距离泛化仍待验证。

不要写：已解决任意动态未知障碍、100%静态成功、独立动态24项通过、SAC独立带来全部收益、已证明无限安全/递归可行、已达到实时性或已验证实机。

论文力量的正确表述：重点检验“观测一致的不确定性表示与真实执行器制动/后备接续能否共同减少安全停滞”。当前组合结构和单个前瞻参数本身不足以证明强新颖性；RAS说服力需要明确机制增量和公平实证。
