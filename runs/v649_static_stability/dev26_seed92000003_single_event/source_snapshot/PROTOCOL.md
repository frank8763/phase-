## 开发修订26：自体几何准入和优先余量回退

92000003单/双圆柱均以零障碍接触停止，原结果全部保留，不能从分母删除。真值横截面审计没有证明该矩形足迹任务不可行；旧足迹+0.15m回退和精确欧氏矩形距离的离线搜索仍未找到路，不能简单归因于0.18m设置。

发现并校正预测模型转向关节限位：实际±0.52rad，旧预测为XML默认±0.45rad。新geometry_memory对齐实际关节限位，并使用机器人/地面预测模型的机体坐标系几何传感器，计算每个预测原生状态的所有活动机器人碰撞几何投影支撑范围；不读取任何隐藏障碍真值。

固定自体配置准入域为[-0.44,-0.375,0.44,0.375]m。该域不是假定机器人永不越出：每个预测状态和预测末态必须包住全部自体几何且余量≥0.002m，否则拒绝该控制候选；每个实际原生物理步重新按当前关节/轮向/根姿态计算自体投影，任何越域立即失败并停止。圆柱使用实际轴向的精确投影支撑，不再把轮子一律当外接球。完整场景模型和机器人几何没有缩放或删除，足迹硬净空仍0.15m，普通动力学准入仍0.155m，制动尾段和终速要求不变。

预测与逐步参考在10组240步控制上的状态对照通过；预测传感器几何与逐状态运动学重建误差<1e-11m；200组独立圆柱表面参数采样检查投影支撑覆盖通过。初版BODY惯性坐标系错误导致几何帧验证失败，修为XBODY机体坐标系后通过；失败检查保留，未用于导航。
