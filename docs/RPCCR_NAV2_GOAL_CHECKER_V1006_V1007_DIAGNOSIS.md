## 精确接口原因

实际A_forward配置仍指向experiments/v945_rpccr_observation_liveness/motion_bt.xml，其FollowPath只指定controller_id，未给goal_checker_id。controller_server同时注册general_goal_checker和recovery_goal_checker，无法在空名称时唯一选出插件。实际错误为“FollowPath called with goal_checker name ... which does not exist”，明确列出两个已加载检查器。实际全局规划有成功返回，因此不能将本次停滞解释成A*或Smac无路，也未发生恢复控制与普通控制交抢。

这是整合检查遗漏：之前两个保存恢复态走直接恢复输入，非普通NavigateToPose行为树；非物理交接peer同样绕过了实际普通FollowPath动作，实际ROS导入检查也不覆盖端口绑定。它们不能作为普通Nav2行为树的完整软件资格。
