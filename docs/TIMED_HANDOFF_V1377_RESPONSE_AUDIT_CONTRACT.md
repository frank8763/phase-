# 响应包络审核：已具备拒绝逻辑，尚无实际移动见证

同一TIME_BOUND_NEXT_SEGMENT候选的逐原生响应审核合同已建立，0模型/积分/预测/物理重放，今天4/4组件与全部计数保持。该合同只读取样本和参考，不产生车辆状态，不授予物理准入。

位置误差以rear参考点计：每个实测车体中心和航向先按原.3米偏置换算rear。审核按原生tick连续性和.01秒时钟逐项绑定，不允许重写起点或暂停来源时钟；原因果系数来源不得晚于起点。对每个样本寻找同一参考中的非递减相位匹配，要求位置误差≤.02米、航向误差≤.1弧度、时间偏差≤.2秒，固定首末参考点；这是离散匹配的充分检查，不把“靠近某个路径点”当成按时跟踪。

原V1378准备数据391个状态回读通过，最大rear偏差.008732827米、航向偏差.028066895弧度；航向与原独立审核精确相同。准备中间时钟由原生tick推导，末时钟直接对保存FINAL_PACKET核验，未冒充新增独立时钟测量。准备的实际输入范围及原审核保持，不向移动状态泛化。

移动段仅用明确标记的软件参考夹具核验审核逻辑：936样本的理想夹具和.1秒延迟夹具满足检查，但两个结果都保持actual_moving_response_qualified=false及physical_admission=false。最早可行相位匹配会在静止和容差重叠区域利用到.2秒范围；这不是把物理时延测为.2秒。位置/航向越界、时钟与来源错配、缺步、非有限body、停车尾非零、末车体/转向未停稳、后驱目标未清零、未来系数和把夹具重标实际等13种负例拒绝。没有已注册实际移动证据时，审核接口直接拒绝“实际移动”标签。

停车尾进一步单独按动作核验，避免把最终观测误算为控制动作。新建的仅样本审核器存在一个源级边界缺口：391个状态的最后200个元素包括末状态，可能漏看实际200个尾动作中的第一个。人为把该动作改成非零，原样本审核器会接受，反例保留；这不是原V1378物理审核缺陷，也没有篡改真实原件。新action_tail_contract包装要求N个已施加动作对应N+1个状态，逐项绑定动作起点/下个状态/请求/applied，并对最后200个动作逐一验零；末状态不计动作。原V1378的390已施加动作和完整200真实零尾再次通过，199零动作加末状态、未施加动作、错tick、请求不符及缺动作5个负例全拒绝。以后必须使用这个包装，不能单独用样本检查宣称完整停车尾。

目前审核合同覆盖的是已记录样本的离散位置/航向/时间成员关系、源时钟格式和完整零动作尾。样本上的单调相位匹配不自动证明实际连续运动、未来不变性、可安全刹停、原生间误差界或递归安全；源码标签亦不能代替来源/模型/控制/接触/全状态重放的独立真实性审核。合法目标、名义路径、软件夹具和监控越界停车都不能单独填补这些证据。
