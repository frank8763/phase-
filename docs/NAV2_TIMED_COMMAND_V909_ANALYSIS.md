# V909：从反复退让转向有限执行与刹停合同

## 问题与改变

V907在三次退让后重新回到同一堵点：名义路线能找到，但每个行驶姿态都要求未来六秒原地驻留，两个目标不一致。另一次决策把native8985车体与8986扫描混读，独立因果审核拒绝。原失败保留。

V909把车体状态与因果障碍支撑集放进同一原子快照。全局Smac/RPP只提供名义路径和命令；实际命令需要通过独立的有限执行检查。每次最多承诺0.2秒，包含后续两秒刹停；观测陈旧、接收延迟、位姿误差与采样间运动均进入距离余量。未获续证只能执行剩余停止响应，不能把一次停车解释为永久安全。

设当前观测支撑界为h_i，方向为单位向量n_i。候选车体矩形沿常Twist参考运动，0.2秒后名义位置固定，真实偏差由经验平移/转向界覆盖。在每个公共时刻tau，要求至少一个方向满足车体最小投影减去[h_i+actor半径+0.08*(扫描年龄+延迟+tau)]大于0.155米及额外车体误差余量。已知静态障碍另用完整矩形距离检查。采样间的位移/旋转/actor移动用Lipschitz余量覆盖，保存审核使用两倍采样密度独立计算。

这不是新的普适安全定理。0.04米和0.035弧度只是固定工况资格与在线监测的经验条件；所有初态/摩擦/控制序列的可达集尚未验证。停止后的持续安全、完整可达性和任意遮挡都没有得到证明。原先六秒驻留充分条件被显式替换，不能声称原合同不变。
