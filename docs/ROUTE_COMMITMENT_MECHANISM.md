# V689路线接续修订的机制与边界

V688将因果未来位置外覆盖投影成空间区域，用来提前规划绕行；随后又每步以这份投影检查旧路线，容易在实际命令仍可获证时频繁重写路线。完整旧日志15次重规划中13次只有投影触发，当前联合占据下旧局部路线仍安全。另2次发生在前后段换向期间，30步净位移抵消，而同参考弧长已经推进。该诊断只说明这15项具体触发，不证明全任务只有这两个原因。

V689保留初次未来投影搜索，修改两项提议维护规则：旧路线局部段以当前因果联合占据重核验；停滞需要同时满足旧净位移/航向条件和同参考弧长进展不足0.08m。路线偏离、当前占据失效及接近路线末端等原触发保留。网络仍为V688冻结checkpoint，没有在6m增加梯度。

此处“保留路线”只影响生成哪些候选动作。实际每个动作仍需通过原完整原生动力学预测、合法执行器命令、2.4秒普通与3.28秒首步加尾段的联合未来占据检查、自体覆盖、末速和实际完整状态接续。新提议规则不会直接写入物理控制；若没有可准入动作，原保留安全尾和停止逻辑继续生效。

因此新增规则不靠缩短预测或降低净空取得进展。它也不自动获得无限安全、递归可行或到达定理：原有限3.28s尾到期、未来观测更新和不确定外集扩张的限制仍存在，所有物理结论仅由实际原生审计支持。

相同网络、物理模型和规范初态的开发对照中，V688学习版900步未到达，V689在629步到达；首次完整状态/控制差异在旧第一次重规划的71步。主规划9→1次，普通倒车201→43步，实际路程10.546668→7.922485m。V689仍执行40步后备并3次通过完整证书切回，不能描述为无后备一路直达。该结果把修订与行为改变联系起来，但两项维护规则仍需单独消融，也不是统计优越性或网络贡献已经隔离。

V689其余预注册相位/完整重复/条件更长距离结果以最终报告为准；本机制说明不预填未完成任务。完整6米学习课程通过前不进入8米，失败保留真实分母。下一论文验证应单列：投影重核验、停滞进展条件、冻结网络与无网络基线、等计算预算，防止把额外候选或排序奖励的作用当作学习改进。
