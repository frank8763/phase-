## 保存输入诊断与有界修订

失败轨迹在中央墙前已经偏离参考：native6000位置误差约.188m、航向误差约-.284rad，7412步位置误差约.568m；不是仅在终点最后两米失败。原生矩形包络在失败姿态净空.137730872m，实际关节几何包络.149498425m，两者定义不同，不能混当同一测距。

V1301回放软件继承了静止夹具的ROS零twist/零yaw，原结果不能当实测速度响应；V1302明确绑定保存真实速度/朝向后复核。V1302把56步扩到160步，方向响应未显著改善，不能靠单纯增加预算声称修好。

按上游1.3.13源码核对，PathAngle会在角差小于max_angle时跳过，PathAlign会在预测最远点数小于offset时跳过；这提供可检验的参数激活假设。V1303在两固定真实保存输入做2×2门参数对照，输出合法，但未达到预登记早转向准入。V1304是本轮唯一配置修订束：更重路径跟随/方向、取消直指终点的GoalCritic代价；真实早状态中位角速度.006465909rad/s，仍低于固定软件准入.01，未启动新的物理重跑。软件修订、原失败和不可归因部分分别保留，不让未合格候选再次接车。

现有证据不能判定算法理论无效或泛化性能，也不能将适配失效称RP-CCR全面优势。后续需要与当前执行器响应一致的预测/命令接口，以及同原生模块的真实测量反馈资格；PRIEST等必须完成车式/完整足迹适配再运行。
