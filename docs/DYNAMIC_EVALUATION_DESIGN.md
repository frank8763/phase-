# 动态论文验证设计（未执行）

2026-11-01。设计稿，不是预注册确认清单或已完成结果。V670仅是同一开发任务的感知修复；下一轮是否需要新开发或确认必须由实际结论决定。所有已失败版本/种子保持分列。

## 能够被否证的主假设

仅保留有限制动轨迹不能避免恢复结束后的信息死锁；若终端约束同时保留可执行制动和可继续取得约束信息的能力，则在明确的运动、感知和几何条件下，能提高动态走廊恢复的严格到达率。当前后一方法尚未实现/证明。这是研究假设，不是成果结论。

现阶段要分开的三个原因：

1. 观测已提供足够信息，但矩形外包络把非凸排除区域重新填回；
2. 所有兼容运动的外推仍过宽，需要动作改变后续观测几何；
3. 估计和几何均足够，但现有搜索/控制候选及实时计算不足。

应先用固定记录数据区分这些原因，不能反复调运动速度、障碍尺寸、起点、阈值或种子取得一个成功。

## 必须公平的对照

强对照至少包含同一感知外集合、完整自体和执行器约束下的标准动态预测局部规划，以及一个独立的时间/运动规划方法。时间规划要含实际加减速和终端制动，不能让基线碰撞后才停而让本文方法享受完整安全过滤器。开发旧失败版本只用于定位机制，不能替代强基线。

消融采用相同任务、初态、真实运动及噪声序列：普通制动尾；保留有限反向制动尾；加入同包正/负测距约束；未来若实现，再加入终端信息续接。存在接口差异时报告继承模块与独有模块，不能把所有改善都归于新增机制。SAC若未在配对中控制其作用，论文不声称SAC贡献。

应同时提供相同墙钟预算和相同展开/候选工作量两种核对。固定展开提升复现，不证明在线实时性；实际预测常耗时高于仿真时间，需报告延迟中位数、95%分位及最大值，不只平均值。

## 开发通过后的新池确认

先冻结最终实现，再生成从未用于调参的完整任务表及纳入规则，开始导航前锁定。几何布局、运动轴、初始相位、速度和遮挡/噪声水平分别覆盖；移动物体直径保持小于静态物体，完整扫掠包络避开通行口保护区，并有完整自体的0.15m永久绕行参考。离线合格证的真值和参考路径不能传入在线算法。

公开全部尝试、筛选拒绝、运行中断、超时和未执行项，不替补失败。动态工程门槛必须另行事前注册；静态23/24不能直接当动态总体保证。同场景重复检验确定性，不能当独立新样本。

每项报告严格到达、最小原生净空、逐原生障碍/穿透/未知接触、自体覆盖、模型首步误差、完整状态重放、集合漏覆盖、执行/私有预测/审计积分和墙钟。有限未来网格覆盖不能声称任意连续时刻保证；更不能由零接触推出活性。

## RAS主张边界

可辩护的论文需要一个清楚的恢复机制、条件分析、强配对对照、多几何新池证据及诚实的失败边界。当前只有有限静态工程通过、动态开发负例和若干机制核验，尚不足以主张一篇证据成熟的RAS论文。目标期刊匹配不等于录用或创新已强。
