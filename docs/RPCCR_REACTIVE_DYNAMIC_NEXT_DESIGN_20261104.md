# V807之后的单问题设计：时间对齐参考与可观测的安全续行

本轮事实和范围见RPCCR_REACTIVE_CONTINUATION_V807_REPORT.md。下列是下一版本设计，不是已实现/已运行/已通过的算法。RP-CCR名称及风险与进展约束连续恢复研究主线保持，不能把集成文献方法直接称新颖性成立。

先改全局参考的时空表示，不同时捆绑新的跟踪器、动作库、传感器或阈值。用原A*静态走廊作拓扑参考，节点/段附候选到达时间或安全时间区间；只在相应到达时间检验由当前真实测距得到的保守actor可达集。允许有完整停稳合同支持的等待与绕行，不能用整个6.56秒占据并集永久抹掉所有目标姿态。有限范围外没有可证未来则明确返回需要新的观测/局部参考，而非伪称全局已达门。完整8+320实际执行合同仍独立核验，不能把空间可行参考当动力学安全。

技术依据：[Phillips与Likhachev, SIPP, ICRA2011](https://www.cs.cmu.edu/~maxim/files/sipp_icra11.pdf)研究在路径规划状态中保留安全时间区间，指出将动态轨迹当静态障碍会漏掉等待或不同时刻通行的解。该原方法的模型与已知动态信息条件并非我们的未知噪声actor，不能直接借用完备/最优/实时保证；Ackermann转向、加速度、跟踪误差和保留尾须另外验证。

下一步先使用303/375/380/674/714五个原保存输入，仅做零模型参考几何/时间一致性核验，目标：揭示原并集拒绝与分时检查的差别、记录所有无证情况，原静态/自体域/风险边界保持。不从真实未来/场景相位生成在线时间表，不通过降低速度上界或删障碍制造可达。保存资格通过后，才另立一个同原任务的有限实际导航，不能重写V807失败。

观测连续性是后续独立因素：绕行时尽可能使actor保持在已有可用射线/视野中；如果实际连续未命中，按真实观测老化外集合并减速或执行原保留尾。不可假设未来测量必来，稀疏32线对直径.20m远处actor的漏采与5%噪声漏检需分别计数。是否增加主动朝向/观测代价，应在时间参考修订单因素验证后单独注册，不直接改传感器。

关于未见域安全，[Firoozi等, OA-MPC v2, 2024](https://arxiv.org/abs/2211.09156)把潜在遮挡运动体的可达集合和终端停车约束纳入MPC。本轮V806/807在检测前主动撤去这类在线未知域约束，是较弱的反应式对照；即使后来到达，也不能宣称任意遮挡突入安全。若论文声称更广未知安全，必须另行设计/证明并验证可见性与停车距离条件。

公平比较与论文后续：同场景、观测、噪声、车辆、初态和安全/墙钟工作预算，分别报告发现、停车、重规划、到达、最低净空、私有模型步数、运行墙钟、观测年龄及失败。此设计不是对比结果或RAS录用保证。
