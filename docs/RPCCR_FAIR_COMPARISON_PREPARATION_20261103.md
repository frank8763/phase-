# 其他算法对比：接口准备与准入清单

准备稿，尚未执行任何外部算法比较。完整场地冻结确认通过后，再根据实际场景与可复现代码确定外部方法版本；实现、论文来源及适配差异须逐一核对，不能用旧失败版本冒充强基线。

| 固定项目 | 各方法共同要求 | 必须单列的差异 |
|---|---|---|
| 任务 | 相同起终点/实际模型/障碍运动及相位/噪声键；清单导航前冻结 | 开发、验证、测试和完整重复分开 |
| 输入 | 相同原始测距、已知地图、公开运动类上界与起步先验 | 原文要求额外信息时作为独立特权设置，不能隐给真值 |
| 控制 | 同一车辆、完整自体、执行器限制/滞后与合法控制日志 | 学习提案/几何控制/安全监督各自参与率 |
| 安全 | 相同.15m实际净空、原生步接触和全状态重放 | 是否拥有额外保留尾/模型/安全层，保持公平或显式消融 |
| 计算 | 相同可用CPU/线程、单任务墙钟和候选/展开上限 | 实际私有预测积分、节点、延迟p50/p95/max、截止超限 |
| 主指标 | 全清单严格到达、碰撞/安全拒绝、超时、未执行 | 不把零接触停车算到达、不删失败、不混合旧结果 |
| 代价 | 路径长度/时间、倒车/停滞、目标退步、重规划/恢复次数 | 未到达的短路径不能当效率优势 |
| 论证 | 完整算法与分项消融；配对结果与不确定性 | 共同前缀等计算不等总计算；机制小样本不是全面优越 |

优先保持可复现的输入/输出适配层：每方法输入公开任务ID、相同观测包和机器人状态，输出合法转向/轮控；统一评价器记录原生状态、接触、净空、实际计算和状态控制重放。外部算法代码冻结、开发预算和依赖检查完成后再登记比较协议；本稿不代表外部方法已实现。
