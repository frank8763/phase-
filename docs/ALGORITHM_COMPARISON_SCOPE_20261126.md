# 合理比较的对象和证据范围

本研究原120个锁定slot及所有失败保持不变。新增说明用于正确解释方法，
不把未执行方法改成0%成功率，不把整车组件当正式对照，不补做旧失败。

导航对照目前实际完成RP-CCR、DWA、TEB、RPP、MPPI各12项。SVG-MPPI已通过
一次当前原车控制/完整停车/重放/独审，持续重规划接口与正式12项仍待准入。
PRIEST已完成作者求解和首控制绑定，完整车辆响应未资格。SCCR原版相机/深度
输入缺失仍是适用性问题；不借用真值、补零或mask后声称原版复现。

PSF、PCBF的方法身份还需要区别处理。PSF接收名义控制器提出的动作，根据
模型、状态和不确定性检查或修改动作，是安全过滤框架；它自身不指定一套
完整导航器。[PSF原论文](https://arxiv.org/abs/1812.05506)。PCBF通过辅助软约束
预测问题、收紧与终端barrier提供恢复机制，其保证依赖相应模型与终端条件。
[PCBF原论文](https://arxiv.org/abs/2105.10241)。

因此，推论是：把这两项作为车辆对照时，必须事前明确并固定名义控制器、
车辆/误差模型、终端条件及每步求解实现。仅运行标量LP夹具不能说明已复现
导航性能。可设计相同名义控制器下的未过滤/PSF/PCBF比较；该设计目前只是
方法适配建议，原slot不更名、不删除、不自动启动，也不借用论文的保证。

现有零到达也必须解释具体边界。例如DWA common01的保存停车预测最低原始
净空0.242684711m，原要求0.243534210m，差约0.000849499m；这说明那次保守
几何门拒绝，并非已观察到真实碰撞。原阈值保持。TEB原始优化输出、其明确
披露的ROS饱和映射和共同执行域需要分别报告；不能把任一工程接口拒绝写成
原论文方法在所有场景失败。RPP有部分原拒绝回复不再常驻，本轮没有下载或
重构它们；只报告实际保留的原结果和独立prefix审核，不凭空补数。

共同主终点仍为原目标、完整停车和全部独立证据合格。辅助结果应报告正常
执行步数、首拒绝阶段、预测门失败项、实际净空、模型/优化器调用和准确未知。
技术censor与功能拒绝分开。当前只涵盖已知课程新相位、单actor/固定运动类；
方法车速、候选预算与工程适配存在差异，不声称相同计算量、普遍优越性、
实时或未知地图泛化。机制收益和可靠性缺口见PAPER_EVIDENCE_REVIEW_20261126.md。
