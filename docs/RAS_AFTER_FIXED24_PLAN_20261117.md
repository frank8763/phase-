# 固定24确认后的实验和稿件缺口

本计划条件是V1248完整24主分层门、固定1/9/17完整重复、全部原生与独立审核和来源SHA回读通过。当前仍在运行，不能预先宣称验收通过。不得因本计划启动第二实例或修改运行冻结源。

24项池已经多轮用于失败分析，属于暴露的固定回归/机制确认集；完整重复验证确定性，不能当独立统计样本。即使本批全过，也只能支持声明的已知静态地图、单小actor、观测及运动先验、登记EW课程与分段安全合同；不能推出泛化、实时、形式化全局或递归安全。

## 实验顺序

1. 冻结成功模型、科学代码、任务和证据，汇总主分母/分路线/方向/失败/重复/计数。新增独立外部评价器，分开在线计算、物理执行和离线审核成本。
2. 强基线和机制消融先进行接口资格与少量公开开发。外部基线候选为同全局参考的成熟RPP、Ackermann MPPI，以及模型适配合格后的PRIEST。与原版/保守安全门控RP-CCR共同配对，禁止拿旧坏模型或未调通实现充当正式基线。所有方法同模型、原始观测、足迹/控制约束、任务与开发预算；统一离线安全评价。内部安全过滤器作为额外条件单列，不强迫所有外部方法使用本方法的恢复逻辑。
3. 对同一合格名义控制器做独立消融：关闭当前状态重新生成、去除恢复入口主动构造、统一额外储备替代分段合同、仅短段可行而不验证后续完整目标等。保持原实际安全终止，候选动作、预算与控制器变化单列。若某关闭项不构成安全可执行控制器，报告为保存态拒绝或保守停止，不向实际执行不合格控制。
4. 开发/调参完成后一次冻结所有算法与参数，另定此前未用于调参的holdout：初始actor相位与观测噪声、起点和目标、地图几何分层。噪声/延迟/参数失配超过原证书假设时单列为合同外压力测试，不能承诺原保证。场景数依据实际配对差异和不确定性制定，不任意许诺固定样本数量足够。若观察测试失败后改算法，原测试转开发，新设未见测试。
5. 实时性单独验证：感知/估计/生成/认证/控制提交与实际生效的端到端p50/p95/p99/max、截止超限、旧命令继续执行和安全退出。物理时钟与actor在计算中连续推进，禁止用lockstep暂停时间充当实时性能。CPU/GPU加速只能在合法资源分配下单独限定、重复验证数值和安全行为；不访问或抢占Stage资源。
6. 仿真全链及实时/延迟资格通过后接实体软件接口：转向/驱动控制、编码器/定位/雷达/TF和时间同步、急停、受控低速响应，再静态、单动态避让及少量基线配对。当前用户明确实体软件尚未接入，模型与实机误差需要重新量测，禁止把当前经验模型原样当实机误差界。

主表报告全清单到达、实际最小净空/接触、安全停止、超时、路径长度/完成时间、停车和恢复次数、计算量和时延。配对报告本方法救回和损害的任务及区间；重复不扩大独立样本数。失败回合不能用短路径或短运行时间声称效率优势。

## 稿件工作与边界

仓库已有docs/paper_ras/MANUSCRIPT_WORKING.md草稿及CLAIM_EVIDENCE.json；内容存在旧版本状态和旧Nav2/SAC叙述，尚非可投稿初稿。方法收敛为候选贡献：从当前实测状态和原因果域建立可执行恢复入口，再衔接保有后续目标可行性的完整恢复路线。原预测/控制/完整后备与连续影子的作用必须用消融确认。

须重新检查与预测安全过滤器、运动规划/跟踪误差方法和已有恢复/可行性方法的差异。工程修复、采用Nav2、扩大搜索和强日志不单独构成新颖性。当前最新恢复不由SAC在线决策，不能把未使用的RL写作核心；是否加入学习策略应作为有对照证据的另项研究，不在当前成功版本上强行捆绑。

重写方法符号与假设、分段2mm/计划44mm/整路22mm储备合同及局限、实验分层与统计、失败案例、复现包和视频。只有证明足够时写条件性理论结论；完整停车尾不自动意味着面对移动障碍的无限时安全。性能与创新证据决定是否具备RAS投稿条件，24全过不等于录用保证。
