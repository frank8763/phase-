- [OA-MPC，arXiv:2211.09156v2](https://arxiv.org/html/2211.09156v2)：将隐藏运动体的前向可达集纳入MPC，配合终端停止约束。其传感外包集合与后续递推有明确覆盖假设。本文不是“随便停住即无限安全”的依据，我们的有限328步尾也不能由此推断递归可行。
- [Visibility-Aware RRT*，arXiv:2406.07728v2](https://arxiv.org/html/2406.07728v2)：将有限视场和可见性约束纳入全局参考规划，而不是仅在末端碰撞过滤。它提示应在失去安全动作前考虑观察方向；但该文的感知受限模型不能直接等同我们含5%漏检的隐藏动态占用。
- [PA-MPPI，arXiv:2509.14978v3](https://arxiv.org/abs/2509.14978v3)：利用感知代价引导轨迹暴露未知区域。这支持研究主动观测目标，但预期信息收益不能替代Phase当前逐原生安全证明；飞行器与本线车体原生动力学也不同。
- [OcclusionCBF，arXiv:2609.06342v1](https://arxiv.org/html/2609.06342v1)：已有工作直接结合隐藏动态可达占用、后备rollout和已验证终端集。其Assumption 2及更新后的重新认证是理论条件，不能由一次末速小于阈值代替。

## 对RP-CCR的具体判断

本轮567个旧状态尾证明的是原动作库的有限联合资格全部不足，不是全局控制不存在。结合上述文献，本线下一研究重点应从“多排几个恢复动作”转向**提前观察与后备续证的联合调度**，同时区分当前安全、有限可恢复和持续可通行。

可检验假设：在原保存第73/90/130步（扫描后、首次退让前、成功续接后），用已经注册过的±8低平移观察合同，分别核验原完整328原生准入、实际测距更新、具体后续完整原生合同及公开目标进展；原门或任何独立审计不通过就拒绝，不通过时不进行完整导航。该项尚未执行，不能声称已得到持续观测闭环、终端不变集或新算法增益。

RP-CCR仍是本线方法名称；“可达占用+后备”“主动观察”等已有组成部分不能独立充当原创证明。论文增量需要落在可验证的连续走廊交接、信息续证和通行性能上，随后用同传感/同动力学/同安全门和明确计算预算的外部方法及消融检验。当前全场动态未通过，未新增对外算法胜率或RAS可录用结论。
