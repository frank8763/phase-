# 下一阶段规格：空间路线与原生时序执行的一致性

这是未执行的研究规格，不是本轮第三候选、额外预算或验收结果。V674/V675原窗口、源、分母与失败不可回填。任何后续实际积分先另立有界协议；当前不增加场景、训练或实机。

## 首要前置：统一执行器合法命令

本轮收尾发现两版本各10步裁剪前证书命令与实际ctrl不同。下一步必须先将硬范围/速率投影作为唯一命令映射，同时用于预测、缓存、后备、日志和物理执行；last_command应保存实际合法命令。先在原锁定异常状态272/294附近验证完整首步、后备、实际ctrl和速率，禁止用裁剪规范化回填旧PASS。在线原生/公开状态核验需加实际ctrl，首次异常即停。全部原失败与原审计保留；在此前置通过之前，不启动新的时序导航方案。

## 已有证据能排除和不能排除什么

V674证实14次中途可证恢复仍未到达；固定217证明最高分普通安全输入无后备而次高分可接续。V675已据此实现最多3个不同首输入的联合筛选，其完整最终结果在V674报告中。两项是控制结构修复，不是无限安全、全局可行或论文新颖性证明。

大部分保存的空间计划到达几何目标，但执行停留在障碍附近。因此不能把所有失败解释为找不到任何空间绕路；也不能仅因空间有路径就推断真实执行器和动态占据下存在通行轨迹。当前尚未独立证明唯一主因是传感、输入库、评分或空间—时序脱节。

## 先做零积分分解

对最后候选完整日志，按时间列出每次规划失效、档段切换、普通候选/后备候选拒绝、可证切回、实际目标进展。统计每条全局几何路线存活步数、行进档序列和实际跟踪偏差；将长期停滞分成“路线失效”“普通库无安全输入”“所测输入无后备”“已有可续接输入但没有持续全局进展”。对于覆盖较松或观测老化的时段另记，不把其与运动学原因合并。

还要核对用于搜索的栅格启发是否与最终联合占据几何一致。当前连续几何检查覆盖了非凸并集，但网格引导来自构建时地图；这仅是待检验的偏差来源，现无因果结论。先从原输入重建比较，不能直接改规则后再声称旧失败被证明。

## 有界可执行运动原语诊断

选定旧任务中事前锁定的少数真实状态，使用相同因果联合位置—速度外覆盖，比较原恒定目标后制动的输入库与两阶段、执行器限速的输入序列。全状态原生积分必须经过run_phase.sh，不能用理想瞬时停车/换向，不能把障碍真实未来或轴/锚点供给候选。先只做固定检查点，完整列出可行与未测项，证明库是否确实漏掉一类安全推进序列；没有增量就不启动导航。

若有增量，再设计显式带时间和控制状态的局部规划：节点含可重放的完整机器人状态、时间、上一命令，边为同一原生动态原语。普通未来占据与后备接续使用同一时间基准；保留原安全门槛及完整自体域。第一条边执行后保留完整匹配尾，求解失败不得丢旧证书。输入序列的分支数/深度/积分量及墙钟必须事前限定，不能无限搜索或边失败边加预算。不能仅用几何终点距离证明任务活性。

## 论文验收顺序

先恢复原失败开发例且同版本完整复现，再冻结算法、另立全新任务池及强对照。需要同传感、同计算预算的预测控制与可更新后备过滤，分开证明测距删失约束、位置速度相关性、中途更新、联合候选与时序原语的增量。报告到达、实际原生安全、停滞、干预、积分量和墙钟；无独立确认前不报告总体成功率或RAS成熟度。

有限证书必须继续标明到期边界。要主张递归可行或任意长安全，还需有效终端/逃逸策略与适用条件；本轮没有这一证明。进一步提高计算量也可能损害实时性，必须实测，不把单CPU串行等同实时。
