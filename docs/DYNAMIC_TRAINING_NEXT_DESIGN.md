# 6米学习版未通过后的下一设计（未执行）

V688原9000秒协议已按依赖失败条件关闭，不使用剩余时间/梯度额度刷模型。已成功6m teacher一次，并真实监督更新512次；学习版在同模型/规范初态900步仍距目标1.074496m。8m未启动，相位变体和重复也未执行。后续仍优先6米，不能把teacher的成功代替训练模型通过。

参考控制普通倒车146步，目标净损失1.012786m；学习版201步，净损失1.751297m。实际路程9.680337→10.546668m，首次完整控制/状态差异step32，与第一条实际学习提案一致；经过不同的重规划，参考控制从上方、学习版最终从下方绕行。两次均0后备接管，不能把这轮差异归咎于保留后备执行。

网络12维输入只有机器人状态、路线局部目标及目标steer/speed；**未包括因果运动集合、观测年龄、重规划历史或路线侧别记忆**，也不以最终到达时间作为监督。teacher标签本身也包含往返。单轨迹MSE拟合和固定.025排序奖励，并不直接优化可持续目标进展。数据关联和遗漏提供了需检验的机制，尚未唯一证明训练失败原因。

下一次有界候选建议先注册以下检查，再冻结模型与任务清单：

1. 评估固定路线侧别/切换成本、真实目标进展及当前几何子目标的冲突；保留必要反向，不直接禁倒车。本轮32/103/132三个锁定投影输入的纯前进搜索未找到有意义全局进展，只有零积分几何负例，不能据此证明全部前进机动无解。
2. 在学习模型实际访问的状态上，使用同样因果信息向已通过参考控制查询标签，聚合数据；将因果belief外边界/速度区间/观测年龄、当前gear、规划侧别与切换历史加入训练接口。查询仍须原生物理和完整接续验证，不能将最佳几何候选当已可执行控制。
3. 监督预测与后续可持续进展/跟踪质量分开，比较无学习、固定额外候选、学习但无.025奖励、学习完整版本，隔离“多一个候选”和“排序偏好”带来的影响。禁止训练过程根据评估失败反复调参数却把同例称留出。
4. 先在6m固定开发任务收集、训练，再事前固定相位/初态评估与完整重复。冻结后任何失败都保留；6m全部门槛通过才进入8m。更多训练距离或更多epoch本身不构成修复证据。

这些只是下一版设计，尚未实现新的动态学习模型、额外梯度或仿真。原Phase20/Phase6保持不变，Stage完全隔离。

文献原文：[Ross等，DAgger，AISTATS2011](https://proceedings.mlr.press/v15/ross11a.html)讨论动作改变后续观测分布及交互数据聚合；[Zhang与Cho，SafeDAgger](https://arxiv.org/abs/1605.06450)讨论参考与学习策略访问状态不匹配及选择性查询。它们支持研究这个方向，但其性能或安全保证不能直接移植到Phase。本轮每维特征都未超过teacher归一化5倍标准差，也不能证明联合状态分布完全覆盖或不存在分布变化；不得仅凭两条轨迹就把失败命名为已证实的covariate shift。
