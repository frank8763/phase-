# 已有全局路径为何没有跟踪通过：V796复盘

用户要求的流程正确：沿既有全局路径正常行驶，动态障碍实际挡住通道时，再依据真实观测重规划至原目标。当前完整场地尚未走到这一阶段，失败发生在动态actor首次发现之前。需要先解决原路径的实际执行闭环，而不是把已有路径搜索成功称为动态导航成功。

## 已确认的事实

1. **全局路径存在，而且静态几何上可通。** 原153步在线产生的175点全前进路径早于本轮起点200。871个加密姿态的全矩形静态净空最低0.180281m；考虑最近采样姿态之间的平移/旋转Hausdorff上界0.005754m后，连续插值姿态净空下界0.174527m，超过0.15m。这里证明的是给定矩形的静态几何，不是实际车辆动力学、曲率变化速度、感知可维持性或动态安全。
2. **车只完成了两段有限跟踪。** V796从原200实际状态出发，两段各328原生，沿原路径弧长推进0.669410m，实际走0.693915m，倒行投影仅约0.000912m。末横向偏差0.096335m、末朝向偏差0.176799rad（约10.13度）。未跨中央x=0、没有发现actor，最高原任务目标进展2.930695m，未超过原V793的2.979145m。
3. **本次停止的直接门槛已分解。** 第三段192个原有限组合提案，全都通过静态净空、自体域、末平动和末角速度检查，全都被未来因果未知风险净空拒绝。最高的最低未来净空仅0.082954m，发生在第328原生，而准入要求0.155m。这支持“当前风险/感知/执行衔接卡住”，不能推广为所有物理控制无解。
4. **模型复制没有表现出数值失配。** 1600原生旧控制回放、656原生实际新分支、656原生整条分支回放和164包实际测距均通过；原生qpos/qvel/ctrl、完整integration state、mocap、实际包/因果域/真实接触一致，误差0；实际最低净空0.305892278m，坏接触0。这不能替代完整路线的实际跟踪验证。
5. **执行时序是明确可检验的疑点。** 当前组件每次把3.28秒控制和制动全部执行完才优化下一段。6.56秒实际时间中，1.64秒平动及角速度均已<=0.025。固定实际姿态的几何风险查询表明，终点当前下界约0.197m，但在旧信息继续老化的查询中约1.04秒后就低于0.155m。这些是几何查询，不是新增刹停预测或物理证明；尚未做因果消融，不能断言全部失败由停顿导致。

## 对“路径错了，还是控制跟不上”的回答

现有证据没有支持“全局路线在静态几何上就走不通”。路径规划仍使用理想转向参考，跟踪器使用实际动力学，安全门再要求整车在未来未知占据域中有可保留刹停证书。三者尚未完成联合可执行性验证。当前被明确触发的失败是最后一层，而短距离跟踪也尚未证明整条路线能完成；不能把问题全推给地图、动态actor或某一个控制器。
