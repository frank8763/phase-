## 证据支持的原因

这条新绕行确实能把车带向横向通道；失败触发来自长时间单锚点预测误差累积，而不是本次碰撞、源码变化或控制器不一致。误差从新增1000步3.60mm量级累积到5000步25.20mm，再到14144步40mm。具体轮胎/速度参数误差的唯一物理因果尚未证明。

从原实际状态重新起算，固定1/2/4秒预测最大位置误差分别6.499/6.669/9.244mm，航向最大.005335rad，均在原门内。窗口重叠且出自同一失败轨迹，是开发诊断，不是独立确认。
