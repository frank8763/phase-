# 多车GPU并行训练与当前论文推进安排

用户2026-11-06提出同机器人复制多份并行训练、训练场应小且独立于当前大场景，并授权按时间有限的现实合理安排。已有RTX5060 Laptop/8151MiB与CUDA PyTorch可用。新任务不自动改变旧训练/SAC禁令对应的已结束轮次，不改冻结网络/current/runtime，也不把并行吞吐测试冒称新策略训练或动态验收。

## 术语和框架

- Gymnasium是环境/向量环境接口；它能对多环境采样进行批处理，但仅套VectorEnv不会将CPU物理自动搬上GPU。[Gymnasium官方VectorEnv](https://gymnasium.farama.org/api/vector/)。
- 视频中大量同机器人平行训练常见于Isaac Gym及后续Isaac Lab。Isaac Gym已废弃，新的框架路线是Isaac Lab。[NVIDIA官方说明](https://docs.nvidia.com/learning/physical-ai/getting-started-with-isaac-lab/latest/isaac-lab-basics/01-the-isaac-platform.html)。
- Isaac Lab当前3.0可使用Newton无Isaac Sim的标准安装，不能把“Isaac Lab一定要装庞大渲染器”当事实。但当前环境Python3.10，官方3.0要求Python3.12；整套迁移存在额外依赖与机器人接口验证成本。[官方安装说明](https://docs.nvidia.com/isaaclab/isaac-lab/installation)。
- MuJoCo Warp提供NVIDIA GPU批量物理并支持与PyTorch联动。它不要求复制当前完整场地；可直接使用同车本体和小平地模型，降低资产转换与动力学迁移成本。它追求总吞吐，官方明确单个世界的低延迟不一定优于CPU MuJoCo，不能保证用GPU即可解决本车80ms完整证书。[官方MJWarp说明](https://mujoco.readthedocs.io/en/latest/mjwarp/)。

## 本轮选择：先测轻量并行物理，不先装完整Isaac栈

先做V846有限GPU后端资格：私有依赖目录、不修改共享Python；同车本体+平地、无旧大场景/相机/渲染，64个独立世界起步，允许预先锁定128世界吞吐对照。每世界只有自己的状态和独立控制，不产生车间碰撞。此“训练场”是新独立小模型，旧完整场地仍为未修改验收场。

保留本体质量、惯量、关节、执行器、碰撞体与摩擦。仅去除视觉mesh、材质、相机等非碰撞渲染资产，XML差异和编译体/关节/碰撞数量需核验；不把简化训练资产冒称原完整模型已验收。并行批次显存/接触缓冲/溢出/数值有限性、总物理步每秒与单世界控制时间分开报告。8GB不能预先承诺几千个复杂机器人可用；从实际峰值和速度选择64/128，而不是追求复制数量。

安装/接口准备与正式资格分开：依赖只装runs/v846_parallel_backend_qualification/deps；固定MuJoCo Warp版本匹配原MuJoCo3.9，保留wheel SHA，不降级或升级共享环境。准备可保留入口/版本错误并在冻结前修正，正式GPU物理资格一次冻结、明确900秒绝对窗口与11月7日08:00根停止界；失败不自动反复更改求解器/模型救回。GPU模型入口新增隔离包装，沿用tools/isolate.py的只读仓库、隐藏home、仅runs可写、网络/PID/IPC隔离，只开放CUDA设备。本入口明确属于新GPU物理后端，不能用原默认禁CUDA入口冒称GPU执行；旧run_phase.sh和tools/isolate.py原字节保留。原模型资格/执行审计继续走原run_phase.sh。

## 训练何时开始、训练什么

当前慢因在线预测/认证/全局参考循环，非策略正在训练。因此先验证批量物理能否解决预测成本，和近似GPU提案的模型偏差。只有后端/接口和同车控制行为通过，才形成一个单独有界训练协议。

若需要学习，优先训练“局部参考跟踪/短段进展提案”而非重训整套动态导航：同一策略汇集64/128独立环境的经验，目标/参考、起姿、速度等使用开发种子变化，冻结独立验证种子。奖励必须同时约束跟踪、前进、平滑和碰撞，不能仅奖励目标距离导致穿越几何。无真实actor未来、无确认池泄漏；训练场可用的全状态与部署观测不同必须清楚区分actor/critic。候选策略输出仅作为提案，不能绕过原生安全门。

建议单次有界先导（例如90分钟）先看独立跟踪指标是否改善；确有收益才考虑后续训练，不能以总奖励上涨代替实际原生整车到达。当前未开始任何PPO/SAC或神经网络参数更新，未设定或承诺训练小时数。训练方法、门槛、总墙钟和停止条件将写在启动前的独立协议中；无需在backend吞吐未明时赌通宵训练。
