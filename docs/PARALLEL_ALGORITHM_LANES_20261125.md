# 其他CPU并行算法推进

用户明确要求其他CPU同时运行算法，并要求先恢复RPP。RPP从未执行的common03接续；common01日志技术中断与common02挡位拒绝/独审次错保留。新audit仅对已执行控制检查执行准入，未执行原始拒绝仍保留，4个坏执行负例拒绝、10个数值/控制模块namespace字节不变。RPP SOURCE16045和远端链已通过。

CPU6准备运行原Deadband/Coherent MPPI一个新数值查询，CPU7准备同时运行原SVGuidedMPPI一个新数值查询；各独立进程组、锁、输出、ROS域、临时目录，Phase只读且Stage隐藏。每个最多一次构造/一次查询/300秒，单独设置内存6GiB和2GiB、证据合计16MiB。这是真实算法核心数值资格，不是完整车辆对照；车辆响应、完整2200停车尾和全状态审核资格尚待完成。原作者近似模型内部工作量未知，不称0或等工作。MPPI随机流复现和GPU数值后端尚未通过。

新SOURCE16023已通过实际CPU亲和/隔离写入/未准入拒绝检查，0算法DLL、构造、优化、物理与重放。原V1987因父metadata超过2MiB而拒绝，0算法调用，失败永久保留；V1993使用绑定原parentmanifest SHA的精确delta，不扩2MiB。SOURCE远端链完成后才启动实际数值。

正式双物理实验仍受15GiB总峰值与每种方法安全资格限制，不能用“已经编译”代替合格或强开两套plant。当前足够运行一条完整物理线和两条短算法数值线；后续按各资格结果推进独立车辆lane。不得修改运行中的冻结源、放宽安全门或重跑失败正式样本。
