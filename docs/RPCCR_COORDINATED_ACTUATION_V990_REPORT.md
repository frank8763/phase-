## 修正的具体问题

原实现先独立限制两个前轮转角，再对两个后轮追加偏航反馈；各执行器幅值和变化率合法，却可能不对应同一个转弯运动。实际保存的四帧6124/6144/6184/6229在独立检查中全部失败，而且除了前/后轮不协调，两前轮分别限速后也可能失去共同曲率。

新实现只使用一个虚拟曲率生成两个前轮目标和两个后轮轮速目标。先求前轮角、后轮速度、逐轮变化率及虚拟转向.6rad/s的共同可行域，再选择曲率和公共速度，不在最后独立裁剪四个目标。偏航反馈仍使用原1.5增益及.16等效偏航目标帽，但反馈作用于共同曲率；纵向PI仍为8/4及原积分边界，公共速度可因协调约束而下降。此候选仅用于前进恢复，公共后轮目标非负；新鲜倒行请求明确拒绝。

停车/过期输入保持前轮目标，按相同转弯关系共同降低后轮目标直至零，避免两轮各自削减后又失去协调。原模型、执行器幅值/变化率不变；不修改路径、车体参考点、雷达、actor、原跟踪门或完整停车尾。
