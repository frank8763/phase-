## 更明确的原因：未来信息余量耗尽

V739仅对同一批保存轨迹作归因，567/567通过已知静态几何，567/567通过原自体及末速门。冻结当前风险集合、仅在计算中不推进未来时间的反事实有561/567过净空门，但原随未来时间扩张的风险集合0/567通过。这表明这些固定尾的限制来自未来未知占用，而非已知静态几何、自体越界或制动末速。

这个“无未来老化”对照只是区分原因，**不是可执行证书**。未发现actor时，控制器不能证明未观测区域没有移动体；停车也不会自动缩小其可能位置集合。未来3.28秒内的风险膨胀会侵蚀净空。最佳停车尾虽全程速度已低于0.025m/s，却分别在预测2.97/2.64/2.32秒首次跌破0.155m。仅仅“车已经停住”不等于能持续安全等待。

旧实际姿态的几何保持诊断也显示：第73步扫描后3.28秒下界0.272378m；第90步降为0.083328m；第130步退让后曾恢复到0.233312m，但第135步又到0.154077m。第176步当前几何下界仍0.208741m，未来保持姿态却仅约0.32秒后就低于门槛。几何姿态保持不是原生可执行动作，以上数字不能替代完整动力学资格。

这提供了可检验的算法判断：当前RP-CCR有有限安全后备和局部连续交接，尚缺在信息余量耗尽前持续触发观察、更新风险域并接回通行的闭环条件。它解释本次有限动作库为何失去资格，但不证明全局控制无解、任意地图无法通行或感知的全部信息已被最优利用。

## 下一研究方向与论文约束

应先在原第73/90/130步、余量耗尽前核验已注册±8低平移观察原语：原完整328准入→真实测距更新→具体完整原生续接→公开目标进展。只有这些条件及独立审计通过，才另立从头导航候选；本轮未执行这些新分支或导航，不再用相同后期状态刷动作。

文献也要求区分有限制动和可持续安全条件：[OA-MPC](https://arxiv.org/html/2211.09156v2)明确给出传感外包与终端条件；[OcclusionCBF](https://arxiv.org/html/2609.06342v1)把验证终端集及更新后认证作为条件。我们不能直接借用其理论结论。[Visibility-Aware RRT*](https://arxiv.org/html/2406.07728v2)和[PA-MPPI](https://arxiv.org/abs/2509.14978v3)提示将感知放入运动决策，但预期信息收益不能直接用作本线实际安全证明。原文核对与适用边界另见docs/RPCCR_JOINT_RETURN_RELATED_WORK_20261103.md。

RP-CCR仍为本线核心方法；未知占用、后备、主动观察均有相关先行研究，不能单凭这些组成部分宣称强原创。需要证明连续恢复与信息续证带来的实际可通行增量，再进行同条件公平对比。目前没有新增全场动态成功率或外部算法优势。
