# 下一实现接口：带完整控制状态的有限时序原语搜索

这是V679轮闭幕后、零仿真的研究规格，尚未实现/执行/验收；不能绕过已关闭窗口再启动积分或以第三候选继续。本轮仍0动态到达。

V680说明扩充单一“恒定目标后制动”库只在一个普通首输入上有增量，未解决往返；V681说明将短期未来全部同时放入空间图也可能只留下安全前缀。下一项要检验的是**有限控制序列的可执行性和接续**，不继续以缩短安全预测、降低净空或刷场景解决。

节点应为N=(qpos,qvel,仿真绝对时间,上一合法ctrl,原始根时刻的因果belief,已验证尾段及其游标)。qpos含全部关节，qvel含全部速度；仅(x,y,yaw,gear)不足以表达制动/限速/自体状态。时间偏移必须来自原生步数，不使用搜索墙钟。原语通过同一个规范命令映射后逐原生积分，父节点数据复制，绝不写回真实状态或改旧证书。

每条边输出完整qpos/qvel/ctrl/时间/全车身状态，按根时刻belief外推到edge_start_offset+native_tick*.01的障碍集合。不得将每条边时间归零；不得模拟未知未来测距后假称观测已发生。预测内只能保留现有信息并外推，执行真实一步后才能用真实新包更新belief。

必须将完成的控制序列与可制动/逃逸尾合成，再统一检查首8+320原生、原0.155净空、0.002自体余量、0.025末速、范围/速率及完整模型。只有完整已证分支能进入可执行集合；低层几何短边通过不代表整个叶子可接受。未完成叶子可用于有界搜索排序，不能发给机器人。

可比较的首个实验是少量固定两阶段目标序列对原单目标库的增量：阶段切换后允许转角与后轮目标变化，全部通过真实执行器动力学及相同最终尾段。控制目标、阶段时刻、分支数、剪枝数、每点私有积分/墙钟和原失败状态清单必须事前注册；本文件不分配新积分预算。不要先在线盲跑再挑获胜原语。固定217/227/686是可追溯旧输入，不能选择新阳性状态替代旧失败。

叶子代价需单列真实目标距离改善、空间参考进展、控制代价、净空和终端可续接状态，不能仅奖励一条反向几何段的局部弧长。先检验相同根状态是否出现旧库未覆盖的完整可证序列，再决定是否值得导航。保留原门槛后可能仍找不到；这属于有限库/预算失败，必须列出未搜索部分。

实际只执行已选分支首公开步并保留其完整安全尾；新搜索或新观测不能销毁旧尾。新分支需从实际完整状态无缝接入、逐步校验缓存一致，失败仍可执行旧尾；切换动作本身计入证书。如果旧尾到期后没有已证延拓，必须明确停止条件，不能用3.28秒停车尾主张无限安全或递归可行。

先固定状态逐公开qpos/qvel/ctrl误差<=1e-8、原生安全/覆盖/源模型全审计，再冻结同开发例导航及严格到达后的完整重复；之后才建立独立新池与同传感/同计算预算对照。建议消融分别去掉两阶段、保留尾、联合输入和真实目标进展项；未到达时不能只展示无接触曲线。
