# Phase面向RAS的阶段性判断 · 2026-11-01

**可以继续以Robotics and Autonomous Systems为投稿目标，但现状不宜直接投稿，创新说服力尚不足。** 这是对现有实现、结果和已核对相关工作的研究判断，不是录用概率预测。RAS关注自主系统中的机器人控制与学习进展，[官方期刊入口](https://www.sciencedirect.com/journal/robotics-and-autonomous-systems)与本线方向相符；方向匹配不能代替方法贡献和有效实验。

## 哪些现有内容还不足以成为主创新

“SAC加规划器”“动态轨迹预测”“安全走廊”“制动后备”都有大量先例。[SIPP-IP](https://arxiv.org/abs/2302.00776)已研究非瞬时加减速下的时间规划；[RTD-D](https://arxiv.org/abs/1902.02851)区分预测正确性与控制相对预测的正确性，并纳入失败后备；[DYNUS](https://arxiv.org/html/2504.16734v3)已有时空走廊和后备轨迹框架。因此简单组合这些部件不足以建立强新颖性。

严格逐物理步评价、无积分外根状态改写、固定工作量与完整重放是可信研究的重要基础，但主要提高证据质量，不能独立替代算法创新。小障碍、宽运动区和不堵口是用户规定的任务合同，不能当作算法优势。

## 更值得形成的方法主张

在准确定位和已知静态先验下，针对未知物体测距不确定性与短时失去观测，让完整车身、执行器迟滞和制动可行性共同约束走廊恢复；观测不足时能够选择重新观测或有界等待，并最终恢复通行。这一主张仍须验证，不能因给它命名就认为有创新。

| 方向 | 当前证据 | 距离有说服力的贡献还缺什么 |
|---|---|---|
| 静态未知障碍恢复 | 新锁定24项23严格到达，3完整重复，独立物理审计通过 | 同任务强基线、组件消融、跨几何/地图验证；24项工程门槛不等于统计优越性 |
| 因果动态估计与预测 | 旧开发发现约0.049m包络漏覆盖；新264帧测距回放有有限集合覆盖检查 | 新轨迹/噪声/遮挡验证、明确假设与保守性；不能声称概率风险已校准 |
| 动态恢复与持续进展 | 旧3分支及本轮3分支均未到达，暴露退避、包络保守性及规划证书不一致 | 实际到达、持续运动下的安全等待/重新观测、预锁定新池及失败归因 |
| SAC的作用 | 模型冻结且可追溯 | 当前恢复器接管所有轮控，SAC收益未隔离；需实验分离，或收窄论文叙述 |
| 可复现性与执行可信度 | 全车身/接触/完整状态审计基础较强 | 继续保持，并证明性能改善来自提出的机制而非筛选任务或增加计算 |

## 怎样把说服力做实

先让动态方法在开发集真正完成任务，再冻结算法和全新任务清单。V663同源码“起点观测32步”和“直接出发0步”消融已完成，两者有限物理与预测覆盖通过但均未到达；V664当前占据提议仍未到达。V665只在两个冻结保存输入上验证密集搜索边修复，没有导航成功。详细结果见DYNAMIC_INTERVAL_DEVELOPMENT_REPORT.md。

后续公平对照应统一地图/观测、任务/运动初态、完整车身、执行器和计算预算。除内部消融外，还需一个独立时间规划基线；不能将当前版本与旧评价口径的Final300直接合并或比较成功率。24项可作工程确认门槛，更强的论文证据还需要事前设计的较大配对评测及区间估计，规模由效果差、任务多样性和算力决定。

当前约7–10倍于仿真时间的计算开销尚不足以声称实时。论文应报告延迟和实时性边界，并优化主要瓶颈。若具备条件，硬件在环或实机会增强实际适用性证据；目前不能写已完成实机安全验证。

最终稿应明确只主张已经验证的内容：若SAC收益没有隔离，就不要把提升写成SAC贡献；若只有有界误差集合，就不要写成校准的概率风险；若仅原生采样步通过，就不要扩展成连续时间安全定理。把上述差距补齐后，Phase才更像一篇具有说服力的RAS方法论文。

## 补充相关工作与下一步差异化要求

未知但有界噪声下的集合估计并非新概念，[Set-Membership Filtering with State Constraints](https://ieeexplore.ieee.org/document/5310323/)已有相应状态约束滤波框架。[Robust Predictive Motion Planning by Learning Obstacle Uncertainty](https://arxiv.org/abs/2403.06222)已在线估计障碍控制集合、构造较不保守的可达区并用于车式机器人鲁棒规划；[OA-MPC](https://arxiv.org/abs/2211.09156)已将遮挡物体可达区与末端停车约束用于动态导航。因此“在线收紧不确定性”“遮挡感知”或“加入停车尾”本身也不能作为首创主张。这些原论文的理论保证依赖各自假设，Phase未复现其完整方法，不能继承其保证。

更值得研究的是：在Phase的稀疏带噪测距、完整车身、真实执行器迟滞下，何时应继续行进、何时应主动获得不同视角、何时能有界等待后恢复；明确什么可观测性/持续通行条件才足以支持进展。离线真实物体不堵口不等于在线可证可通，有限制动尾也不等于无限期停车安全。应分别建立集合覆盖、相对集合的安全准入、条件进展三个可检查主张，再用同计算预算的强对照和消融验证。当前尚未建立这些理论与实验证据，不能提前写成论文结论。
