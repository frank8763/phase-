## 已证实与未证实的原因

1. **当前不是已经撞上动态目标。** V712/V721/V724都在首次发现之前停住。原实际actor仍离车较远，阻挡控制的是观测尚不能排除的潜在隐藏中心域。原地图三条全身几何通路资格已通过，这不代表参考路线已经动力学可执行，也不代表任意动态场地可通。
2. **安全观测无法持续支持原3.28秒全车预测。** 当前32束360°lidar角间隔11.25°，前向15束depth覆盖70°、间隔5°，传感器真实逐.08m射线采样。半径.10m潜在目标可保留在射线间隙或遮挡中。未来3.28秒按原每轴.12m/s外扩的径向上界约.556634m；叠加完整车身和.155m预测净空，能安全停在当前姿态不等于下一完整动作/后备可认证。原前向19候选多次全TIME_CLEARANCE是这一局部证书失败，不是全局无路证明。
3. **只减少退让未改善到达。** 原V724较浅退让的预测最低净空.161302m接近.155门槛，旧V721尾.330481m；最大位移仍同1.452516m，旧曾成功续接、新没有。终端几何可见计数没有保证实际后续观测。
4. **固定短转向没有提供预期的观察扫描。** V728原安全合格的转向分支，车体净偏航约−.68°、−1.02°、+.18°，实际转向关节已响应。由保存的实际转角和纵向速度代入理想无侧滑自行车公式，对应参照约−11.42°、−6.29°、+11.35°。这说明此时段的无侧滑几何直觉与真实车体响应差异很大。**原生预测器与实际完整状态误差为0，不是预测器错估了这些轨迹。** 不能仅据短动作断言车永远不能转、模型参数错误或某个摩擦系数就是根因；需要接触/轮速/滑移与可达曲率的独立诊断。
