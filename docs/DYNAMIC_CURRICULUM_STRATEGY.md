# 动态能力课程与训练对象 · 2026-11-01

用户提出先在空白或原场地训练/验证检测、重规划、跟随通行。采纳由简单到复杂的课程，但先明确当前可训练对象：V680的804步均由几何控制最终接管，冻结SAC的计算动作不是实际执行动作；V683准确当前状态也未到达。因此不能直接以“再训练SAC若干步”推断能修复当前时序准入与动作候选不足。

V686是已实施的能力评测，不进行梯度更新。单个新空白4米横穿任务，车/物理/47束传感/噪声/漏检与原直径0.20m、0.08m/s动态障碍不变；实际开始32步安全观测，接着因果绕行规划和原时间安全控制。真实轨迹仅评价器使用。三层结果分列：检测与运动辨识、因果新路线、完整安全执行到达。简单任务阳性不替代原场地验收或独立确认。

后续课程建议如下，未执行阶段不能填写已通过。

| 阶段 | 测什么 | 进入下一层的依据 |
|---|---|---|
| C0 无障碍短直线/转弯 | 真实动力学跟踪与执行器延迟 | 完整控制/状态一致、误差与进展，避免把控制失败归因动态 |
| C1 原车安全观测单个运动圆柱 | 检测、位置外集、运动证据、观测丢失 | 回波与覆盖分开；速度区间排除0或不同时刻位置集互斥才称运动辨识 |
| C2 空白场地单横穿（V686当前任务） | 原路线失效后新绕行路线及执行 | 三层分别通过，再条件同版本重复；不能只算零碰撞 |
| C3 多固定初态/运动相位和方向 | 课程迁移，防止只记一个例子 | 事前固定开发与留出清单，失败不替换；先开发后冻结评测 |
| C4 原有墙体场地 | 转弯半径、有限信息与动态时序联合难度 | 回原任务，再新池确认，不能拿空白场地通过替换 |

课程增难首先改变任务分布，保持物理、安全、信息假设可比。放慢障碍、公开锚点/活动区、无噪声或稠密真值感知均须另立诊断对照，不能默默用来训练后称原未知条件通过。

若证据显示需要学习，优先考虑学习**历史观测条件下的机动提案或跟踪残差**，并使网络动作确实影响最终控制。尚未实施，不声称新网络已有效：

- 输入：过去传感包与位姿、合法上一命令/当前车速、候选路线误差、因果障碍位置速度集合与观测年龄；禁止真实锚点/正弦相位/未来轨迹。
- 输出：数量有界的多阶段转向/速度机动或对已有安全候选排序；最终仍受原生完整自体/未来净空/合法幅值和速率/有限后备约束。
- 记录原网络动作、实际命令、安全干预及被拒原因，区分提案收益、执行收益、接管率。全部被接管时必须报告，不能拿最终控制成功宣传SAC学会动态。
- 奖励或监督对齐真实目标净进展与新路线跟踪，惩罚真实倒退/停滞/切换；不能只奖励路径局部弧长。安全门拒绝与失败也保留训练账目。
- 训练checkpoint另存runs，Phase20/Phase6不覆盖。启动前另立有限环境步/梯度步/墙钟预算，固定训练与留出集和同预算基线；比较从零、冻结、课程和非课程。V686没有启动这些更新。

论文上课程学习本身已有大量工作，不能单靠“由易到难”建立强创新。需要检验信息历史、动力学可执行机动及安全准入的联合贡献，再用分层失败定位、同输入消融和留出任务证明其必要性。当前没有动态稳定或RAS充分证据结论。

检索原文：[Narvekar等，JMLR2020课程学习综述](https://arxiv.org/abs/2003.04960)讨论任务序列和知识迁移；[Wang等，Grounded Curriculum Learning](https://arxiv.org/abs/2409.19816)讨论训练任务分布与目标任务相关性。以上课程和网络接口是本项目的设计判断，不是文献已证明对Phase有效。
