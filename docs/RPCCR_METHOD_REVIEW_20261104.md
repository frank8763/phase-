# RP-CCR完整场地瓶颈复盘与方法研究路线

本文件区分已验证事实、文献方法、待检验假设。当前完整场地动态仍未通过；空白课程V70024/24、静态V65723/24与新场地开发分开。原失败及所有旧截止不改。

## 复盘结论

V791把148次全局规划降到3次、146次参考复核失效归零，但最大实际目标进展约2.94m，仍未跨中央开口、未发现3m量程外的actor。可见“全局能搜索到路线”和“按原生动力学持续安全推进”之间仍有缺口。step248有13个原安全首命令，仅前三个做完整后备检查；另10个联合可行性未知。末557的25个有限候选全部未来净空拒绝；有限库失败不等于所有控制无解。不能继续仅调目标分数、延长墙钟或用新的版本号代替机制验证。

## 主线建议：保留RP-CCR，研究观测驱动的可恢复进展

建议将贡献集中为：在动力学可执行的安全后备约束下，选择能够恢复后续前进能力的观察与推进动作。暂不改名宣称一个已完成的新算法，也不以组合A*、MPPI、CBF的数量说明创新。

记当前因果信念为B_t，状态x_t。原有限联合安全集为

\[
\mathcal U_{\rm joint}(x_t,B_t)=\{u\in\mathcal U_{\rm fixed}:\text{合法首段及至少一个完整原生后备均通过原门}\}.
\]

第一步先查清该有限集合，而不是只对普通得分前三名判断后就认为无可用控制。之后可研究“观察是否使正进展的联合安全集合恢复”以及完整后备净空余量的实际变化，替代仅最大化可见面积或盲目缩短退让。未来预期观测只可用于提案/效用，不得授权安全；证书只能由已经收到的真实测距包更新。

拟检验的增量有三项：一，普通候选与完整后备联合筛选，排除排序截断导致的假不可行；二，基于后续可执行性/证书余量而非通用信息熵的观察调度；三，保留有进展的走廊承诺并在真实新证据出现后更新，避免观察—前进—倒退循环。第2/3项是研究假设，当前未实现、无性能保证。仅第1项若成立属于搜索完整性修复，单独不足以支撑强RAS创新。

MPPI可作为扩大有限控制提案覆盖的工具或公平基线；它不是安全证书。优先使用固定、可复算的有限提案完成瓶颈判别，必要时再引入有固定随机种子/工作预算的MPPI或CEM，所有输出共用原门。暂不启动SAC训练，避免同时改变策略、传感和安全层而无法归因。

## 下一轮实验顺序及判据

1. V792：原step248、原13首命令完整资格；前三旧拒绝必须精确复现，余10逐一验证，完整分账静态与未知未来风险。600秒、无新导航、无新动作。由独立保存审核判断是排序遗漏还是本原语库全部拒绝。
2. 若发现遗漏且原生实验证书合格，才另立一个完整联合准入候选；若全拒绝，优先定义更早的观察—推进资格，而不把“加大MPPI采样”当已解决。所有后续物理源/任务/阈值事前冻结，共享本轮独立总截止，不重开旧批。
3. 回到同一原起点，以首次发现、实际328刹停、运动条件全局重规划、真实继续≥1m和到达为完整功能门。三原路线开发及同版本完整重复通过后，再单独冻结新24确认；旧已见任务不混入新分母。
4. 论文机制试验使用相同地图/任务/测距噪声规则/车模/控制/安全门/积分预算，比较RP-CCR原版、联合准入、加入观察调度、完整机制，并与可运行的外部控制器适配版比较。分别报告全部私有积分、墙钟、到达、发现链、净空、倒行、证书恢复率。等算力消融与充分预算性能比较要分别定义，不能把更多采样隐藏成机制优势。

## 面向RAS的实际缺口

需要可复现的完整动态结果、相对已有主动感知/安全规划的清晰机制差异、组件消融、足够独立任务与不同几何/速度/漏检条件的公平比较，以及动力学/安全/进展主张相匹配的理论或明确有限范围。严格零接触、完整自体与原生重放是可靠证据基础，但不能替代算法增量。没有任意遮挡下必到达定理，也不能对无界失观测承诺必然进展；录用不能承诺。
