- [OA-MPC v2，2024-10-23，对应后续TCST论文的公开修订稿](https://arxiv.org/html/2211.09156v2)：式2e使用互补约束，原文明确允许机器人不动时避碰约束失效。因此其递归可行性不是本项目停止期间也保持零接触的相同保证。可借鉴因果可达集合与保持旧计划的证明结构，不采用这一安全放宽。
- [PA-MPPI v2，2026-02-11](https://arxiv.org/html/2509.14978v2)：感知代价把目标相关的未知边界纳入控制序列优化，避开纯跟踪控制器面对遮挡时的限制。其有限代价、四旋翼模型和GPU实现不等于本项目原生全车身完整后备证书；不能把引入MPPI或信息奖励本身当新颖性。
- [Action-Aware Pro-Active Safe Exploration，2025](https://arxiv.org/html/2503.09515v1)：强调行动可实现的信息收益和避免无信息末段运动；有限时间证明依赖静态环境及安全持续单轮车路径跟踪假设。本项目的有界动态未知运动、有限射线、随机漏检与转向/制动滞后不能省略。
- [Dynamics-aware navigation，RAS172(2024)104582](https://www.sciencedirect.com/science/article/pii/S092188902300221X)：动力可避免性而非仅距离可支持安全规划；其同类比较也说明，RAS论证应明确控制机制与反事实对照，而非单独展示成功视频。

## 已取得的新诊断证据

V792原step248的13首命令/228后备中：228条静态几何、自体与末速度全部过门；219条因未知未来净空失败、9条全部门通过。原前三的63条后备全部未知未来拒绝，最佳未知界约.145112m<.155m。剩余10个首命令中9个联合可行，真实328原生验证误差0、最低实际.305892278m。它同时揭示普通候选截断和未知域未来余量的影响；仅看已知地图可行不能推导持续可执行。

这些输入的普通240步预测向前，但完整紧急尾实际会倒退约.305–.348m。V793因此只修有限普通联合搜索的完整性，并从原起点测试持续闭环；不是声称整尾前进、全局到达或证明递归安全。当前已实际在step248选择原rank3命令，原样保留所有原门，后续整体结果仍待完整功能和独立审计。

## 推荐的算法结构

保留RP-CCR“风险与进展约束的连续走廊恢复”主线。更有研究价值的扩展是**可恢复性约束的主动感知MPC**：同时考虑走廊进展、真实控制可行性、信息更新对后续合法前进能力的影响以及换向代价。

1. **提案层**：必要时用有固定工作量的MPPI/CEM产生多段转向/轮速序列，覆盖“先转再行驶”等当前近似恒定目标库不易表示的机动。它仅生成提案；不能替代实际车模、完整自体/控制/净空证书，也不能用未来actor真值优化。
2. **证书层**：当前已收到的因果测距、运动界和完整原生预测决定首执行段与紧急后备能否承诺。未来预期观测只影响效用，不能作为当前安全依据；新观测实际收到后才能续证。
3. **主动感知层**：观察价值优先由其是否恢复后续正进展的联合安全控制、增加多少完整后备余量衡量，而非只计可见面积/熵。这个指标相对已有感知代价是否有独立价值必须实测。
4. **连续恢复层**：保留走廊进展和旧完整尾，在合法交接窗口内重新接入；观察或倒车必须有明确的进展恢复目标，不能无限换向。

以上多段提案和主动感知MPC目前只是下一阶段设计，没有实现、资格或全场性能声明。V793运行期间不追加这些改动。若V793仍失败，本轮停止物理修订，保留明确的失败接口与静态/未知/动力分解，再另立有界资格，不无证据添加动作池或刷种子。

## 如何检验增量与论文主张

- 工程修复：原RP-CCR与完整联合准入，同原动作库/原门/同任务，报告搜索截断假不可行率与全部增加的计算。这个修复本身不足以支撑强创新。
- 机制消融：完整联合准入基线、通用信息收益调度、以恢复合法前进能力为效用的调度，分别固定控制提案空间与安全层。真实新观测与无新包历史域对照，用实际续行/到达而不是预计可见面积判定。
- 外部对照：可复现的MPPI及感知代价适配版、可行的动力约束MPC适配版，明确适配程度与文献假设。任务、观测生成规则、车模、控制、安全边界和总工作量公平；在轨迹分叉后不能要求传感包仍相同。等计算比较与允许各方法充分预算的比较分开报告。
- 验收顺序：已见组件资格→原起点完整链→三路线开发与完整重复→另立新池确认→几何/速度/感知变化及公平比较。旧空白24、开发与重复不混入新分母，三路线不当三地图。
- 理论主张：有限库完整联合选择可给出清晰完备性命题；更强的持续安全/进展结论必须显式写观测可获得性、未知运动类、模型误差与合同到期条件。随机5%漏检不能自动当作有限时间必获新观测，不能先宣称任意遮挡下递归可行或必到达。

面向RAS可争取的中心贡献应是“受真实动力约束的安全恢复与控制相关信息价值的统一”，并以机制消融和独立泛化证据支持。方向有研究意义，当前证据尚不足以宣称创新已经成立或录用可保证。
