# 静态失败与修复的研究解释

本轮目标是修复路径执行不一致，不把通用路径跟踪改写为新颖算法。原V650冻结确认13项11到达2未到达，第二次失败预定停止，不能将早停样本比例当总体成功率。两个失败有完整目标几何路径却反复倒车/重规划；所选控制预测下一位置与实测逐值一致，说明当前优先定位高层路径与低层执行、进展目标的协调。

修订28只改变打分：同挡路径上的真实投影弧长增量替代朝固定前视点的距离收益，预测终态朝向与同位置参考朝向比较，不再通过前视朝向偏差使进度奖励接近零。仍逐原生预测完整自体足迹、刹车尾、端速和净空准入，路径投影不跨换向点。它在93000074同初态1104步救回，重建原生净空0.1927867m；但局部停滞未消除，且该修订暴露1次最近点索引换向旁路。

修订29控制性补齐：索引不得自行跨过有意换向点；规划曲率由自体关节和执行器限位约束，保留原控制候选范围供纠偏。±0.52rad内轮限位与0.6m轴距、0.54m轮距，理想Ackermann中心角约0.42722rad；原35°规划角与机器人执行约束不一致。该结构边界不等于轮胎滑移系统的动力学可达证书，原生预测仍必须验证所有命令。

借鉴来源：

- [Regulated Pure Pursuit](https://arxiv.org/abs/2305.20026)：曲率、速度和碰撞前视协调。
- [Nav2 FeasiblePathHandler](https://docs.nav2.org/rolling/configuration_and_development/configuration_guide/core_servers/controller_server/controller_server_plugins/feasible_path_handler/)：有意换向点作为局部目标，检查位置与姿态后再放行。
- [Liniger等作者MPCC实现](https://github.com/alexliniger/MPCC)：路径进展与轮廓误差联合优化。当前使用有限候选原生预测和投影评分，不是完整非线性MPCC求解器。

论文力量来自进一步验证的可观测性—路径—实际自体执行的一致性问题与可复现实证，而非这些常规控制组件的命名。后续需：冻结后新池确认；同初态原评分/投影评分、规划限位、换向门控的组件消融；同地图/感知/足迹下RPP或纯规划跟踪等对照；并报告全过程净空、停止时间/循环次数、时延和适用边界。恢复器接管全部控制时不能把效果归因于SAC。

目前没有连续时间安全、校准概率风险、实时性或实机保证。静态开发救回不等于独立确认通过，动态保持关闭。
