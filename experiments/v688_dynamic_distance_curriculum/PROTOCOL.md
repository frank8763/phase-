# V688 有界6米→8米动态学习课程

用户明确要求继续解决动态、开始6米训练，6米通过后再更长；此授权允许本轮独立提案网络梯度更新，覆盖旧各轮的“该轮训练0”限制，冻结Phase20/Phase6文件仍不可覆盖。新独立9000秒总窗口，从execute.py启动计时；全部新增实际任务/训练/重放必须在同一个绝对截止前结束，不自动续窗、刷种子或追加算法。最大7实际任务、1024监督梯度步；每任务900秒hard、780秒soft，6m最多900公开、8m1100公开，单CPU顺序。

任务是明确的新空白场地动态开发课程，非原墙体场地验收。起点(-D/2,-2,0)、目标(D/2,-2)，D=6或8米，原±5m区域；原车/传感47束3m、噪声/漏检/圆柱直径0.20m、振幅0.25m、最大速度0.08m/s不变，actor锚点仍(-1,-2)、y方向运动且完整扫掠不堵原中央口。初始化32公开步按原完整安全门观测。真实锚点/相位/当前位置/未来仅用于场景和评价器，绝不输入tracker/planner/网络。

第一项6m teacher是同V680控制候选/联合最多3首输入/保留后备与切回；空间引导改为已验证V678因果3.28s外覆盖投影，提前提出绕开未来可能占据域的路径，原生时间安全门仍使用原联合位置速度外集。原源未改，投影只来自原观测belief；预检全车身扫掠参考、导航后逐329未来样本覆盖、完整控制状态重放和全部物理/模型/因果/证书审计必须通过。teacher未到达即关闭本轮，保留失败，不启动依赖训练或更长距离。

teacher到达并全审计通过后，才以其所有实际普通控制样本进行6m监督行为克隆：12维机器人/路线特征（身体坐标lookahead2、相对heading的sin/cos2、实测前向速度/角速度2、上一合法ctrl归一化4、目标steer/speed2），标签是teacher实际选择候选的合法4执行器目标。无障碍真实几何、未来相位或真值速度输入。MLP12→32→32→4、全tanh、float64，Adam0.001、固定seed688、batch<=128、严格512梯度步/60秒hard。输入归一化由teacher训练集计算，序列不切碎当作独立测试。新JSONcheckpoint只写runs，冻结SAC更新0。

网络目标作为原候选库的一项额外提案，仍经过同幅值/速率、2.4秒完整原生预测+8/320原生后备、.155预测净空、完整自体余量.002、末速.025和联合首步接续验证；合格时加固定.025排序项，禁止网络绕过门。每条候选记录原始网络目标/特征/角色，实际命令与选择审计单列。训练效果需报告被选LEARNED的实际普通步比例；0实际作用不得说网络学会动态，即使fallback到达。

冻结checkpoint后依次6m相位0实际学习版一次、相位pi/2新开发变体一次，全部严格到达且全审计通过、两场各至少1实际LEARNED普通命令执行，然后仅相位pi/2同版本完整重复一次，模型/规范初态/全qpos/qvel/ctrl<=1e-8、实际接触事件一致。共6m最多4导航（teacher+2学习评估+重复）；任何失败即关闭后续阶段。相位变体不混称独立确认率。

只有该6m门全部通过，才执行8m相位0 teacher一次；成功审计后用其数据对6mcheckpoint再512梯度步微调（不改网络/训练参数）。之后8m学习版相位pi/2一次并在成功、有实际LEARNED命令且审计通过时同版本完整重复一次，最多3个8m实际导航。8m通过本轮收尾，不自动加10m；8m失败保留实际进度与失败。训练/开发/重复分列，不能把teacher成功代替学习模型通过。

每任务逐原生接触/穿透/未知0、实际全车身净空>=.15、完整自体覆盖、静态模型不动、无积分外根改写、原始ctrl和预测/执行/完整重放一致。任何物理/源码/模型/真值泄漏异常立即停批；普通导航失败也停止依赖阶段，不替补或降低门槛。原始全部日志、失败、源/协议/模型/训练数据/模型SHA及预算台账保留；最多一次纯初始化/序列化修复需保存原失败并沿用原截止，不改算法或原结果。实现experiments、输出runs/v688_dynamic_distance_curriculum；全部实际积分包括训练中任何环境步仅./run_phase.sh，Stage/实机0。
