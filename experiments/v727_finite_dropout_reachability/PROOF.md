# 有限任务、条件漏检模型下的未知中心域

这是RP-CCR风险集合的一项待验证修订，不声称新算法整体原创、现实风险已校准或无条件安全。旧V721/V724确定性集合与原失败保持。物理净空门槛不改，但新集合是**条件概率置信外覆盖**，不能沿用确定性覆盖保证。

每个公开包47束，至多1201包。公开模型规定每束独立漏检概率不大于p=.05，非漏检噪声被原clip严格有界。障碍位置、车辆姿态和当前可观测几何在本包噪声产生前确定；原单actor规定轨迹满足，任意相关传感失灵或对象利用当前未产生噪声反应不涵盖。实际PRNG/种子是模拟器实现，解析概率结论在理想条件传感模型下成立，不是对特定有限种子族或现实传感器的无条件定理。

机会束的定义独立于当前读数：若某完整网格单元内的所有半径.10m圆心，必包含一处真实float32/.08m射线采样点，且该点距离<R-clip-1e-4，则存在该单元中的真实障碍时，首次命中必早于这个采样点；不漏检的读数不可能精确等于R。用整格半对角线和1e-4安全余量保证，不使用连续理想射线的擦边命中，也不假设看穿静态遮挡。更近的静态命中仍会严格submaximum，所以原结论成立。远处、未覆盖格、量程末端不计机会。

为每个可能单元维护“所有合法历史路径中的最小连续必需漏检数”。按原每轴速度上界做邻域最小值传播；一帧中若该格有任何机会束读数submaximum，保守地把仍有历史路径的计数清零；没有机会保持计数；所有机会均maximum才加机会束数。原可靠submaximum自由前缀和初态先验确定性整格排除不变。达到K=10的格排除。不能累计不连续漏检，也不能把一包重复当独立证据。计数随可能路径传播，不能把静止格历史误当移动障碍历史。

沿真实中心对应的单元路径，最小路径计数不超过该真实路径的计数。只要真实路径未先被排除，排除真实中心必须发生于至少K个连续机会测试都漏检；出现任何有效非maximum机会会清零。帧内包含成功时全部清零更保守。真实路径和机会集合可依赖过去噪声，但每次机会在当前噪声前可预测，故任意给定连续K机会全漏检的条件概率至多p^K。固定全任务至多N=47×1201=56447个机会起点，用并集界得

Pr[任务中任一帧真实中心被置信规则排除] <= N p^K = 5.51240234375e-9 < 1e-8。

此处不需要对假设格/路径数量再做并集，因为控制的是**一个真实中心路径**的首次错误排除事件，最小值递推使错误排除蕴含该真实路径的漏检事件。多个真实actor/重复/新任务必须另分配总预算，本轮不能宣称无限任务或实机校准。空间离散、原确定性排除、运动上界及原生积分正确性仍是条件，不由此概率式替代。未来329原生时刻继续用原运动外扩，概率仅在实际包时刻消耗，不能使用未来预计观测填安全域。

验证必须包括：全零信息反例、非连续漏检反例、相关永久失灵反例明确会破坏概率假设、原始浮点射线整格命中测试、最小计数传播的真实路径不等式、有限序列精确枚举/概率DP与并集界、原记录实际actor全部逐329覆盖、固定完整预测尾的证书变化。即使这些过关，仍须单独有限原生校准和完整功能导航，不能用离线证书叫动态通过。
