# 已知几何条件集合的外覆盖条件及证明补充

本证明只针对V769/V772明确注册的条件运动类：未知物是半径r=0.10m圆形刚体；在公开已知静态实体和边界上不穿透；每轴速度绝对值≤0.12m/s；观测排除规则的原可靠前缀假设成立。未知物未来位置、实际锚点、方向、相位均不参与在线集合。真实场景全相位符合性是条件核验，不是对任意未知运动的证明。

1. **安全删除格子。** h=.01、格半对角rho=h/sqrt(2)。静态实体有符号点距s(x)是1-Lipschitz。若格中心g满足s(g)+rho<r−epsilon，则格内任意x均有s(x)<r，因此不存在该条件运动类下的圆心。只删除这样的整格，所有可能部分容纳圆心的格保留。对多个实体逐个判断的并集仍仅删除不可能格；角点/窄条不做更激进删除。边界同有符号距离。外缘格强制可能，不因有限数组边界虚构远端清空。

2. **当前集合归纳。** .08秒内每轴位移最多.0096<h，最近格索引每轴至多变化1。因此3×3（包含原格）膨胀包含真实下一圆心对应格。该格因非穿透条件不会被静态掩码删除。可靠射线前缀完整单元排除按原V735假设不会排除真实圆心；故“过去集合膨胀∩允许几何∩本次未排除域”逐包仍覆盖。初态全可能与公共3m排除/原真实t0包保留原条件。

3. **未来集合。** 不假设未来测量。第n个.08秒桶仅重复膨胀和静态过滤，归纳覆盖每个桶内任意真实圆心对应格。对任意原生时刻s>0取ceil(s/.08)桶；桶包含起始格且允许循环保持，故同样外覆盖桶内时刻。测试中0–3.28秒最多41桶，0时刻为当前集合，保存42集合。该形式可能因取整而更保守，不声称等于精确连续可达集。

4. **距离下界。** 若当前/未来真实圆心c对应保留格中心g_c，则||g_c−c||≤rho。对于查询点x的最近格g_x，有 d(g_x,P_grid)−||x−g_x||−rho−epsilon≤||x−c||。截断到非负仍为距离下界。完整车体覆盖点加覆盖半径减量、再扣actor半径，沿用原整车连续覆盖证明，得到净空下界。B当前距离再扣sqrt(2)*.12*s由反三角不等式有效；C用未来格集合直接查询，不重复扣速度。

5. **取最大。** B和C均在同一显式条件运动类下是相同净空的下界，因此max(B,C)仍为下界；同时限制已知静态整车净空。全部.155/.002/.025及执行器门保留。下界变化会改变候选选择与真实观测，不能由固定状态“支配旧下界”推断整条闭环一定更好。

6. **历史证书。** 将这些当前条件距离下界输入V742的历史max递推，仍在该条件类内成立。V775独立直接全历史max已验证30条末失败尾无新准入；不因它合法就认为能保证推进。

以上是集合/下界层面的条件外覆盖证明。它不建立本控制器递归可行、无限时安全、终端不变集、统计概率校准、任意地图可达、实机鲁棒或全局到达。原生模型有限重放/329样点验证与上述结构证明并列记录，不能互相替代。

文献背景：Firoozi et al., OA-MPC, arXiv:2211.09156v2；Kim et al., OcclusionCBF, arXiv:2609.06342v1。它们结合可达占据和后备/终端条件，但采用不同动力学及假设。本实现未实现其CBF或终端不变集证明，不能挪用其安全/递归可行结论，也不把“利用已知地图限制运动”单独称RP-CCR原创贡献。
