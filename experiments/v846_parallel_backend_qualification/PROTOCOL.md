# V846：小平地同车GPU并行物理吞吐资格，无策略训练

用户要求同机器人复制多份并行训练、不要在当前完整大场景训练，授权合理安排加快推进。本阶段仅验证新后端能否在本RTX5060 Laptop/8GiB上并行推进64/128个独立车体世界，不开始PPO/SAC，不更新任何网络，不从正式确认池抽样，不改变旧V843/V844/V845事实、源或窗口。

模型仅机器人本体和支持平地，直接取原机器人XML，不包含原完整场地19实体、未知actor、相机图像或渲染管线。可保留XML视觉资产共享，但不渲染或复制大场景。先核对原本体与原已执行scene模型的机器人动力学参数；正式资格用现有SerialRobotPredictor的机器人本体复制逻辑，只读scene作元数据、不复制其环境。关节、质量、惯量、原执行器及接触参数保持，不为后端适配默默改求解器、摩擦或降低物理步长。

依赖mujoco-warp3.9.0.1、warp-lang1.13.0只安装到runs私有deps，原MuJoCo3.9/PyTorch/共享环境不改。下载初选warp1.10.1经metadata发现不满足>=1.13，未安装；下载未完时第一次安装失败亦保留准备日志，冻结前完成匹配。无共享依赖升级/自动CPU回落。

GPU资格入口是本轮新增的隔离运行包装，复用原tools/isolate.py命令并仅添加/dev/nvidia必要设备和CUDA0；保留隐藏home、只读Phase仓库和依赖、仅runs写、网络/IPC/PID隔离。原run_phase.sh/tools/isolate.py不修改。此新增入口仅可执行本资格脚本，不声称原默认禁CUDA入口能用GPU。旧原模型的安全与执行资格继续原run_phase.sh。

首模型前固定900秒唯一绝对截止且不越11月7日08:00/1794009600，正式一次执行，锁定同一execution.lock；无后冻修补/改版本/换求解器重跑。阶段顺序CPU原本体单世界10次预热+512原生基线→GPU64世界和128世界各8原生初始化/预热，捕获8原生步图，最多64次回放=512原生/世界。捕获本身若不执行其物理步，单列捕获工作未知；不伪造0。控制按世界预先确定、幅值与首slew合法，各世界独立不互相碰撞，场景只有平地。没有奖励/终止/更新循环，吞吐通过不称训练成功。

指标：编译/预热时间，批量每8步回放p50/p95/max，累计各世界原生步每秒，实际qpos/qvel有限性及四元数、接触/约束容量与GPU显存占用（不查询进程）。保留原始每世界末状态，检查同输入世界一致性和不同输入世界有差异。GPU/CPU绝对状态偏差只报告，不要求跨引擎1e-8或声称可替代原安全认证。若缺feature/编译失败/缓冲溢出/NaN/预算不足即失败封账，不缩模型或改物理参数救回。

通过仅PARALLEL_PHYSICS_BACKEND_QUALIFIED；之后仍需单独训练环境观测/动作/奖励/重置与独立验证协议，或在线原生证书的GPU误差资格。所有旧失败保留，REVIEW_PENDING原字节恢复、锁释放，原件不删，不自动训练/通宵导航/对照/新24。不承诺8GiB能跑千环境，不把64环境吞吐等同单车80ms实时能力。
